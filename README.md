# marriage-forecast-system

Программная система прогнозирования соотношения браков по регионам Российской Федерации.

## Назначение системы

Проект предназначен для учебного анализа региональных данных и построения простого прогноза коэффициента брачности. Система загружает CSV-файл, проверяет обязательные поля, готовит признаки, обучает модель линейной регрессии, выполняет кластеризацию регионов и формирует текстовый отчет.

Тема проекта: «Программная система прогнозирования соотношения браков по регионам Российской Федерации».

## Лабораторные работы 4-5

В лабораторной работе №4 подготовлена минимальная реализация программной системы на Python с использованием pandas, numpy, scikit-learn и Streamlit.

В лабораторной работе №5 описан план сопровождения проекта: работа через GitHub Issues и Pull Request, стратегия ветвления GitFlow, контроль качества через pytest и возможная интеграция GitHub Actions.

PostgreSQL рассматривается как проектируемая база данных для дальнейшего развития системы.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск Streamlit-приложения

```bash
streamlit run src/app.py
```

Если пользователь не загружает CSV-файл, приложение использует файл `data/sample_marriage_data.csv`.
Сейчас этот файл является шаблоном для ручного заполнения официальными данными Росстата/ЕМИСС за 2020-2024 годы. Пустые значения нужно заполнить перед запуском прогноза.

## Запуск тестов

```bash
pytest
```
