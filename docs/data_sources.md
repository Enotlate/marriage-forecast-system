# Источники данных для CSV

Основной источник демонстрационного CSV: таблица браков из датасета Tochno.st «Социально-экономические показатели регионов России».

Ссылка на источник: https://tochno.st/datasets/regions_collection

Период источника: 2000-2025.

В демонстрационном CSV используются только реальные заполненные строки по коэффициенту брачности. Строки с пустыми, `None`, `NaN` или служебными пропусками не используются.

## Использованные показатели

- `marriage_rate` - раздел «Население», показатель `Y477110229` «Общие коэффициенты брачности на 1000 человек населения».
- `marriages` - опциональная колонка. Ее можно добавить только при наличии в исходной выгрузке числа зарегистрированных браков.

## Период данных

Желаемый период для выборки: 2020-2025. В текущий CSV попали доступные заполненные наблюдения за 2020-2023 годы, найденные в доступной CSV-выгрузке Tochno.st.

Если будет добавлена отдельная выгрузка таблицы браков с заполненными значениями за 2024-2025 годы, эти строки можно включить в CSV без изменения структуры приложения.

## Структура CSV

```text
region,year,marriage_rate
```

Допустимая расширенная структура при наличии числа браков:

```text
region,year,marriage_rate,marriages
```

## Регионы

В демонстрационный CSV включаются доступные заполненные наблюдения для регионов:

- Краснодарский край
- Москва
- Санкт-Петербург
- Республика Татарстан
- Ростовская область
- Свердловская область
- Новосибирская область
- Республика Башкортостан

Если для части лет или регионов нет проверенных значений по обязательным полям, такие строки не включаются в CSV.
