# Источники данных для CSV

Основной источник демонстрационного CSV: Tochno.st «Социально-экономические показатели регионов России».

Ссылка на источник: https://tochno.st/datasets/regions_collection

Период источника: 2000-2025.

Период, используемый в демонстрационном CSV: доступные заполненные наблюдения за 2020-2025. В текущий файл включены только строки, где для региона и года есть полный набор числовых значений по всем обязательным колонкам. Строки с пустыми, `None`, `NaN` или служебными пропусками не используются.

По пересечению выбранных показателей для выбранных регионов в CSV попали 2020-2023 годы. 2024 и 2025 годы не включены, потому что по показателям брачности и численности населения в доступной выгрузке нет полного набора значений за эти годы.

## Использованные показатели

- `marriage_rate` - раздел «Население», показатель `Y477110229` «Общие коэффициенты брачности на 1000 человек населения».
- `income` - раздел «Уровень жизни населения», показатель `Y477110374` «Среднедушевые денежные доходы населения», рублей в месяц.
- `unemployment` - раздел «Труд», показатель `Y477110418` «Уровень безработицы: Уровень безработицы», процентов.
- `population` - раздел «Население», показатель `Y477110461` «Численность населения», оценка на конец года, тысяч человек.

## Регионы

В демонстрационный CSV включаются доступные заполненные наблюдения для регионов:

- Краснодарский край
- Москва
- Санкт-Петербург
- Республика Татарстан
- Ростовская область
- Свердловская область
- Новосибирская область
- Республика Башкортостан

Если для части лет или регионов нет проверенных значений по всем обязательным числовым полям, такие строки не включаются в CSV.
