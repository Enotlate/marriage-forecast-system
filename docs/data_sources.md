# Источники данных для CSV

Файл `data/sample_marriage_data.csv` подготовлен для доступных заполненных наблюдений за период 2020-2024 по официальным данным Росстата/ЕМИСС.

Автоматически получить полный согласованный набор точных значений по всем регионам и всем четырем показателям не удалось, поэтому числовые значения не заполнены искусственно. Строки с пустыми или `None`-значениями в колонках `marriage_rate`, `income`, `unemployment` и `population` удаляются из демонстрационного CSV.

## Поля для заполнения

- `marriage_rate` - общий коэффициент брачности, число браков на 1000 населения.
- `income` - среднедушевые денежные доходы населения, рублей в месяц.
- `unemployment` - уровень безработицы, процентов.
- `population` - численность постоянного населения, человек.

## Регионы и годы

Набор данных рассчитан на заполненные наблюдения за 2020, 2021, 2022, 2023 и 2024 годы для регионов:

- Краснодарский край
- Москва
- Санкт-Петербург
- Республика Татарстан
- Ростовская область
- Свердловская область
- Новосибирская область
- Республика Башкортостан

2025 и 2026 годы не включены, так как для проекта они рассматриваются как прогнозный горизонт, а не как фактические данные.

Если для части лет или регионов нет проверенных значений по всем обязательным числовым полям, такие строки не включаются в CSV.

## Рекомендуемые официальные источники

- ЕМИСС: https://www.fedstat.ru/
- Росстат, демография и естественное движение населения: https://rosstat.gov.ru/folder/12781
- Росстат, уровень жизни и доходы населения: https://rosstat.gov.ru/folder/13397
- Росстат, трудовые ресурсы, занятость и безработица: https://rosstat.gov.ru/labour_force/

При заполнении CSV важно использовать одинаковую территориальную детализацию, одинаковый год и одинаковые единицы измерения для всех регионов.
