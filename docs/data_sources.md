# Источники данных для CSV

Основной источник: Tochno.st «Социально-экономические показатели регионов России».

Ссылка: https://tochno.st/datasets/regions_collection

Датасет подготовлен на основе сборников Росстата. Охватываемый период источника: 2000-2025.

## Использованные показатели

Для демонстрационного CSV используются показатели:

- общий коэффициент брачности на 1000 человек населения;
- среднедушевые денежные доходы населения;
- уровень безработицы;
- численность населения.

## Принцип подготовки

Значения за 2020-2023 сформированы на основе доступной структуры статистической выгрузки Tochno.st/Росстата.

Значения за 2024-2025 являются расчетным демонстрационным продолжением временного ряда. Они подготовлены для проверки работы программной системы на расширенном горизонте и не должны рассматриваться как официальная статистика.

Демонстрационный набор используется для проверки загрузки данных, валидации, прогнозирования и кластеризации.

## Структура CSV

```text
region,year,marriage_rate,income,unemployment,population
```

В CSV включены все регионы, для которых в используемой выгрузке найден полный набор базовых значений за 2020-2023 по выбранным показателям. Для каждого региона добавлены строки за 2020, 2021, 2022, 2023, 2024 и 2025 годы.

Строки с `None`, `NaN`, пустыми значениями или текстом в числовых колонках не используются.
