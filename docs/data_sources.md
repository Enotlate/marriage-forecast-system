# Источники данных для CSV

Основной источник демонстрационного CSV: Tochno.st «Социально-экономические показатели регионов России».

Ссылка на источник: https://tochno.st/datasets/regions_collection

Период источника: 2000-2025.

В демонстрационном CSV используются данные из таблицы браков и связанные показатели численности населения. В файл включаются только строки, где для региона и года есть полный набор числовых значений. Строки с пустыми, `None`, `NaN` или служебными пропусками не используются.

## Использованные показатели

- `marriage_rate` - раздел «Население», показатель `Y477110229` «Общие коэффициенты брачности на 1000 человек населения».
- `population` - раздел «Население», показатель `Y477110461` «Численность населения», оценка на конец года, тысяч человек.
- `marriages` - расчетное число зарегистрированных браков на основе показателей Tochno.st: `marriage_rate * population / 1000`. Так как `population` в источнике указана в тысячах человек, при подготовке CSV она переведена в человек, а `marriages` округлено до целого числа.

## Период данных

Желаемый период для выборки: 2020-2025. В текущий CSV попали доступные заполненные наблюдения за 2020-2023 годы.

2024 и 2025 годы не включены, потому что в доступной CSV-выгрузке Tochno.st для выбранных регионов нет полного набора значений по показателям брачности и численности населения за эти годы.

## Структура CSV

```text
region,year,marriages,population,marriage_rate
```

## Регионы

В демонстрационный CSV включаются доступные заполненные наблюдения для регионов:

- Краснодарский край
- Москва
- Санкт-Петербург
- Республика Татарстан
- Ростовская область
- Свердловская область
- Новосибирская область
- Республика Башкортостан

Если для части лет или регионов нет проверенных значений по всем обязательным числовым полям, такие строки не включаются в CSV.
